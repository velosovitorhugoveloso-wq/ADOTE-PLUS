# Adote+ 2.2 — Central do Processo e Programa de Apoio

Projeto demonstrativo de uma plataforma de adoção responsável para ONGs.

## Novidades da versão 2.2
- Central profissional do processo de adoção, com protocolo, resumo, etapas, pendências e próximos passos.
- Área de Meus Pedidos mantida para consulta individual das solicitações.
- Programa de Apoio às ONGs com indicadores de impacto, organizações e registro demonstrativo de apoio.
- Novo visual institucional, cards, hierarquia de informação e modais responsivos.
- API `/api/apoios` preparada para registrar apoios no PostgreSQL.
- API `/api/apoios/indicadores` para indicadores do programa.

## Execução
```bash
pip install -r requirements.txt
python app.py
```
